# MDPro3 决斗动画实验分支

分支：`feat/mdpro3-duel-experience`。只改变决斗中的卡片表现和选择交互，场地的配色、布局、区域尺寸和相机角度沿用原版。

## 对照实现

行为参考 [MDPro3 原仓库](https://code.moenext.com/sherry_chaos/MDPro3)，本次读取的是 [daominah/mdpro3fork 镜像](https://github.com/daominah/mdpro3fork) 中以下文件：

- `Assets/Scripts/MDPro3/Duel/GameCard.cs`：点击、抬起／翻面、发动、无效、确认、对象、表示形式、移动。
- `Assets/Scripts/MDPro3/Duel/DuelButton.cs`：就近圆形按钮、按钮顺序、100 ms 开合、金／蓝边框优先级。
- `Assets/Scripts/MDPro3/Duel/Message/DuelMessage.cs`：发动与连锁时机、攻击宣言与伤害计算、素材与灵摆召唤识别。
- `Assets/Scripts/MDPro3/Duel/BG/DuelBGManager.cs`：多段连锁的卡片对照、编号和逆序结算。
- `Assets/Scripts/MDPro3/UI/Popup/Old/PopupDuelSelectCard.cs` 和 `PopupDuelSelectCardItem.cs`：单击选中／取消、单选替换、双击快捷确认、先选卡再选效果。

没有移植 Unity、AssetBundle 或 Master Duel 的模型／粒子资源。以下表现采用浏览器中的 CSS、少量 SVG 和已有的卡片 spring，实现相同类别的事件反馈；不是商业客户端全部演出的逐帧复刻。

## 已实现的表现与交互

| 类别                                     | 行为                                                                                                                              |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 抽卡／移动                               | 保留源区域姿态，隐藏的卡组槽位出现在手牌时从卡组位置移动；不等网络请求完成才处理对局。                                            |
| 召唤／盖放／翻转                         | 落地环与短促反馈，通常／特殊／反转音效，盖放提示，表示形式旋转而不重复做大幅起落。                                                |
| 融合／同调／超量／连接／仪式             | 用素材消息和卡片类型识别正规召唤；不同颜色和几何反馈，连接门，最多四张素材卡汇聚。复活额外怪兽使用普通特殊召唤反馈。              |
| 灵摆                                     | 无连锁时两张同侧灵摆区域的卡成为对象，识别灵摆召唤；同批后续怪兽沿用该反馈。                                                      |
| 破坏／解放／素材／送墓／除外／返回／洗切 | 限量的离场、收缩、扩散反馈；不生成全屏粒子或旋转大纹理。                                                                          |
| 发动／确认／无效                         | 大图、来源、连锁编号；对方手牌、墓地和除外区发动同样可辨认；无效显示灰色卡图和无效标记。只展示服务端已公开的信息。                |
| 连锁                                     | 当前与前一段卡图并列；完整卡片栈保留到结算结束后短暂消失，可点开卡片详情；区分待处理／结算中／已处理／已无效。                    |
| 攻击                                     | `MSG_ATTACK` 只画指向线；`MSG_BATTLE` 才执行冲击与归位，按属性区分颜色。攻击无效／伤害结束清除指向。                              |
| 对象／装备关系                           | 轻量对象边框；点击卡片可查看服务端查询提供的装备／效果对象连线。                                                                  |
| 阶段／回合／生命值                       | 短提示和生命值增减数字，不做全场震动。                                                                                            |
| 卡片操作                                 | 原下拉菜单改为卡片附近的图标按钮，顺序为发动→攻击→表示形式→特殊召唤→通常召唤→盖放。发动／特殊召唤金色，其余蓝色，选中时增强边框。 |
| 多效果／卡堆                             | 先选择卡片，再选择效果，确认后回传；取消本地选择不会向服务器发送错误的取消码。                                                    |
| 连锁响应                                 | 同卡不同效果合并为一个卡图；强制发动也显示确认界面，禁止取消。原有全部／智能／忽略连锁设置继续生效。                              |
| 对象选择                                 | 全部候选都在场上时直接点卡，确认后回传；其他情况用原生卡片按钮列表，支持切换区域、单选替换、取消选择和双击确认。                  |
| 发动确认／表示形式                       | 发动确认附卡图和来源；表示形式显示竖／横卡图与卡背预览。                                                                          |

## 性能策略

- 没有新增运行时依赖，也没有新增 WebGL／Canvas 引擎。
- 场上装饰效果最多同时 10 个；中央展示卡最多两张，加上完整模式最多四张召唤素材。排队展示最多 8 条，积压时缩短展示，保留卡片栈供查看。
- `CHAINED` 更新正在展示的发动卡，不额外插入一次重复等待。
- 所有寿命由墙钟计时器结束；图片解码和装饰层不阻塞规则消息处理。已有卡片 spring 仍有停帧超时兜底。
- 动效主要改变 transform／opacity。没有背景模糊、逐帧 React 状态、全屏粒子或循环大纹理。
- 低核数／低内存设备默认轻量；仅在有动效时采样帧间隔，持续慢帧可自动降级。自动判断是启发式，不代表实际 GPU 跑分。
- 决斗菜单新增“自动／完整／轻量／减少动画”。选择仅在本浏览器保存；尊重系统减少动态效果设置。
- 标签页隐藏时清除装饰队列并直接落到卡片目标姿态；新局和退出清除所有展示、选择和旧提示回调。
- 展示层和操作按钮使用 viewport portal，避免小屏自适应缩放把测量坐标二次缩放。

## 验证

```bash
npx tsc --noEmit
npm run lint
npm run build
./node_modules/.bin/esbuild tests/mdpro3-experience.test.mjs tests/card-animation.test.mjs tests/eventbus.test.mjs --bundle --platform=node --format=esm --out-extension:.js=.mjs --outdir=/tmp/neos-mdpro3-tests
node --test /tmp/neos-mdpro3-tests/*.test.mjs
npm run test:e2e -- tests/e2e/mdpro3-duel.spec.ts tests/e2e/duel-dialog-regression.spec.ts --workers=1
```

已通过类型检查、lint、生产构建和 15 项单元回归。单元回归检查无动画帧时仍推进、快速消息的队列上限、旧局队列取消、连锁对照更新、提示身份、素材等级组合、指令身份和原始战斗消息的字节解析。浏览器回归检查按钮／效果／场上选择的真实回传，以及快速重置后的提示。浏览器测试需要安装配置指定的 Chrome；本次环境没有该可执行文件，未完成浏览器实测或低性能设备帧率测量。

建议实测同一副卡组：对方手牌发动、三段连锁、无效、各类额外召唤、灵摆、攻击后取消、直接攻击、对局连续重开。低性能机器分别比较“自动”和“轻量”。
